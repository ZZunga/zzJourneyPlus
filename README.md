# zzJourneyPlus

Edge 540 / 840 / 1040 / 550 / 850 / 1050 / 1060 용 장거리·란도너링 데이터 필드 (zzTravel 후속, 이름 변경).
SDK 9.3.0, 타입 체크 Strict(-l 3)로 7개 기종 모두 빌드 확인.

## 표시
- 메인 (아래, 큰 숫자): 주행거리(기본) / 다음 CP 거리 / 남은거리 / 현재시각 / 경과시간
  - 다음 CP, 남은거리는 단위 아래에 작게 CP / REM (단위와 겹치면 숨김)
  - 거리 100 미만은 소수 한 자리(작은 소수부), 100 이상은 정수. 단위 km/mi는 기기 설정
  - 시간이 칸 폭을 넘으면 한 단계 작은 폰트로 자동 전환 (값이 바뀔 때만 폭 확인)
- 서브 (위쪽 줄, 태그 표시): 경과시간 ELP(기본) / 구간시간 LAP / 도착예정 ETA / 여유시간 BUF
  - 시간은 h:mm, 여유시간은 +h:mm / -h:mm
  - 12시간 설정이면 현재시각은 단위 자리에, ETA는 태그 아래에 AM/PM
- 넓은 칸: 아이콘 + zzJourneyPlus(좁으면 zzJourney+) + 오른쪽 라벨, 메인 | 서브 같은 크기로 나란히
  - 높이가 낮은 넓은 칸(550/850의 420x60)은 타이틀 없이 숫자만

## 계산
- 남은거리: 코스 안내 값(distanceToDestination) 우선
  - 경로 이탈: offCourseDistance > 50 m가 5초 이상 이어질 때만 (교차로, GPS 흔들림 무시). 복귀는 바로
  - 이탈 중: 이탈 직전 코스 남은거리 - 그 뒤 달린 거리 (값이 튀지 않게)
  - 코스를 한 번도 안 썼을 때만: 목표 거리 - 주행거리
- 다음 CP: distanceToNextPoint (턴바이턴 켜짐이면 다음 회전, 꺼짐이면 다음 코스 포인트 - 기기 동작)
- ETA: 현재시각 + 남은거리 / 평균 속도. 설정 etaMode 0 = 휴식 포함(주행거리 / 경과시간, 기본), 1 = 이동 평균(averageSpeed). 100시간 넘거나 0.5 m/s 미만이면 --:--
- 여유시간: 진행거리 / 제한 속도 - 경과시간
  - 진행거리 = 코스 전체거리 - 코스 남은거리 (주행거리보다 클 수 없음), 코스가 없으면 주행거리
  - 목표 거리는 진행거리에 섞지 않음 (코스 길이와 다르면 시작부터 마이너스가 되던 문제)
  - 음수면 경고색 (주간 빨강, 야간 핑크 기본)
- 구간시간: timerTime 기준, onTimerLap에서 시작점 기록

## 설정
- 메인 표시, 서브 표시
- 목표 거리 (km/mi, 0 = 사용 안 함)
- 여유시간 기준 제한 속도 (km/h 또는 mph, 기본 15, 0 = 사용 안 함)
- 주간/야간 컷오프 초과 색 (색상표 인덱스는 다른 zz 앱과 동일)
- 버전 정보 (읽기 전용, 시작 시 덮어씀)
